# Project One-Pager

## Problem

Business teams need trustworthy data, repeatable analysis, explainable alerts, and clear stakeholder communication. AI can speed up parts of this workflow, but adoption must include privacy, verification, governance, and team enablement.

## Solution

A decision-intelligence and AI-adoption platform that:

- validates multi-entity time-series data,
- engineers comparable KPIs,
- creates explainable analyst review queues,
- exports reusable SQL-ready outputs,
- demonstrates optional Snowflake integration,
- records auditable AI-assisted development evidence,
- governs Cursor with version-controlled rules,
- and converts individual AI use into a 30–60–90 day team adoption plan.

## Data Boundaries

- Public market data or deterministic offline fallback
- Synthetic operational telemetry
- Synthetic EMEA GTM metrics
- No Red Hat, customer, confidential, or production data

## Strongest Technical Proof

- Python and Pandas pipeline
- SQLite read-only analysis workspace
- Snowflake-native SQL and optional connector
- Explainable event detection and transparent risk decomposition
- Automated tests and 100/100 data-quality preflight
- Version-controlled Cursor rules

## Strongest Business Proof

- Executive decision brief
- Stakeholder questions before action
- Regional GTM review queue
- AI use-case builder
- Skill-gap and onboarding matrix
- 30–60–90 day adoption plan
- Responsible impact-measurement framework

## Interview Message

> AI can accelerate diagnosis, SQL development, and communication, but the analyst must remain responsible for data quality, assumptions, privacy, validation, and the final decision.
