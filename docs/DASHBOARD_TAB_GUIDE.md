# Dashboard Tab Guide

| Tab | Business question | Strongest proof | Demo priority |
|---|---|---|---|
| 1 Overview | What matters now and what needs human context? | Decision brief, quality score, architecture | Essential |
| 2 Trends | What changed and which transparent drivers contribute? | Risk decomposition and entity benchmark | Essential |
| 3 Investigation | Which observations require review and why? | Explainable queue and triage framework | Essential |
| 4 SQL, Data Model & Snowflake | Can analysis be reused outside the dashboard? | Read-only SQL, lineage, Snowflake-native assets | Essential |
| 5 Reliability & Governance | Can the data and pipeline be trusted? | 100/100 quality score and preflight evidence | Mention |
| 6 Operational Monitoring | Does the architecture transfer beyond finance? | Service/version matrix and incident queue | Optional |
| 7 AI Evidence | Where did AI help and how was it controlled? | Problem → prompt → decision → verification → artifact | Essential |
| 8 GTM Studio | Can this become a team capability for GTM Operations? | Synthetic GTM analytics, 30–60–90 plan, skill gaps, Snowflake + Cursor | Essential |
